Sales Forecasting & Performance Analysis (Python + Power BI)
📌 Project Overview
This project builds an end-to-end sales forecasting pipeline using Python (Machine Learning) and Power BI.
Historical sales data is used to predict future sales, evaluate model performance, and visualize business insights through an interactive dashboard.

The project combines data cleaning, regression modeling, forecast evaluation, and BI visualization.

🎯 Objectives
Predict future sales using historical data
Compare Actual vs Predicted Sales
Measure forecast accuracy and prediction error
Identify trends and seasonality in sales
Provide business insights using interactive dashboards
🛠 Tools & Technologies
Python (Pandas, NumPy, Scikit-Learn)
Machine Learning: Linear Regression
Power BI
Power Query (Data Transformation)
DAX (KPIs & Measures)
Time Series & Forecast Evaluation
🔄 Project Workflow
Data collection and preprocessing using Python
Feature engineering and train-test split
Sales prediction using Linear Regression
Model evaluation using MAE & RMSE
Export predicted results to Power BI
Dashboard creation for business insights
